Your library folder

You choose where videos are stored. The archive writes to its media root — {{ media_root }} inside the container, which you bind-mount from any location on your host (the same one you mount into Jellyfin), or change with the MEDIA_ROOT env var. The only structure the app imposes is a per-user subfolder, so each person gets an isolated library:

{{ library_subpath }}

In Jellyfin, add a library (TV Shows, metadata downloading off) pointing at that {{ library_subpath }} folder wherever the media volume is mounted, and grant only your Jellyfin user access. Full path in this container: {{ library_path }}.

Don't point the library at the media root itself or the {{ canonical_subdir }} staging folder — those hold every user's files and the download originals, so Jellyfin would show duplicates.
